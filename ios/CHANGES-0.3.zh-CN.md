# PocketFilm 0.3：可选胶片片边

## 原项目核实

SpektraLab 已有 Film Edge（overscan），不是新增的平面贴图效果。引擎在胶片曝光阶段构建片窗、齿孔、边缘文字、灰雾和漏光，再参与后续显影。

本次核对的提交是 `02d82b56cf65f0f8e802a708612edc4e9a4790af`，证据：

- [桌面端设置与类型 FilmEdge.swift](https://github.com/JamesQiu2005/SpektraLab/blob/02d82b56cf65f0f8e802a708612edc4e9a4790af/modern_UI/Spektrafilm/Spektrafilm/Model/FilmEdge.swift)
- [原生实现 overscan.cpp](https://github.com/JamesQiu2005/SpektraLab/blob/02d82b56cf65f0f8e802a708612edc4e9a4790af/engine/src/pipeline/overscan.cpp)
- [参数定义 params.cpp](https://github.com/JamesQiu2005/SpektraLab/blob/02d82b56cf65f0f8e802a708612edc4e9a4790af/engine/src/core/params.cpp)

本次复用上述引擎和现有参数，没有修改胶片数据、Metal 数学、片边算法或 macOS 界面。

## 如何使用

1. 拍摄前在相机设置中开启“添加胶片片边”，或拍摄后在“胶片成片”页面开启。
2. 选择 135 标准、135 半格、120 6×4.5 / 6×6 / 6×7 / 6×8 / 6×9、XPan、120 6×12 / 6×17，共 10 种画幅。
3. 选择“片条扫描”或“扩孔片夹”。135 片条可以选择白色或黑色齿孔；120 胶片没有齿孔。
4. 可调帧号（0 为自动）、边缘灰雾和片轴漏光。
5. 点“应用设置并预览成片”查看效果；也可直接点“保存 RAW 与成片到相册”，保存前会自动显影当前设置。

片边默认关闭。关闭后重新显影会从完整 RAW 恢复无片边成片；原片从未裁剪或覆盖。每张照片的片边随机种子写入参数文件，重新显影同一照片时保持不变。

打开历史底片会恢复该照片的显影与片边设置；旧版参数文件没有片边字段时默认关闭。设置变动但尚未显影时，分享按钮只分享 RAW，避免把旧成片误当成当前效果。

## 画幅与尺寸

当前锁定引擎要求输入照片符合胶片片窗比例，否则明确拒绝渲染。因此开启片边时，保留照片横竖方向，按所选胶片画幅**居中裁剪 JPEG 中的画面**，再在外侧生成片边；RAW 完整保留。宽幅画幅会裁去更多画面。原生取景框线仍仅辅助构图，不预览片边和片边裁剪。

这版不提供截图中的“片边跟随任意裁剪”、换机身、自由片窗及半格双联功能。135 使用引擎实际片窗 36.25×24.3；其他画幅同样采用引擎表中的尺寸。

原引擎片边不支持分块渲染，本次仅在开启片边时关闭分块，并将送入引擎的画面长边限制到最多 2048px；片边会增加最终 JPEG 外侧像素。RAW 和无片边输出尺寸不受此限制。2048 是本次采取的处理上限，内存峰值、速度与真机稳定性尚未测量。

## 保存与验证

本地继续保留 source.dng（或导入原后缀）、film.jpg 与 recipe.json。相册保存两张独立照片：完整 RAW 和当前胶片成片。片边显影失败时保留原片和已有文件，并停止本次相册保存，避免静默保存旧成片。

Windows 本地可检查：Swift 语法、项目引用、参数与上游 schema、10 种画幅比例、资源与打包完整性。

新增 5 项 XCTest（总计 13 项）：双方向裁剪范围与中心、旧参数兼容与往返编码、设置改变后的旧成片识别、10 画幅×2 扫描样式的真实引擎渲染、结果页 JPEG 与保存文件一致性。这些 XCTest **尚未运行**，需在 Mac / GitHub Actions 的 iOS 模拟器上运行；相册权限、RAW 实拍和内存仍需真机验证。
